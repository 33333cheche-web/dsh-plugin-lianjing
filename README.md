# 莲鲸 · 陪你干活的桌宠

我在屏幕右下角养了条鲸。

她坐在莲台上打坐，闭着眼，头发是海的颜色。多数时候她不出声——我敲代码、放 agent 出去跑、回来等结果，她就在旁边陪着；想看她一眼，点一下，她才抬眼。

她还有正事：**替我看住这一屋子的 agent**。

---

## 正事：一屋子 agent，总得有个看板

DSH 一开就是四五个会话，每个会话底下又挂几个子 agent：跑到第几步了、烧了多少 token、花了多久、上一次有动静是什么时候。这些数字散在各处，翻起来烦。

莲鲸把它们收进一张卡片：按项目串成树，项目下面是会话，会话下面是子任务；有活在跑的时候，她背后转一圈慢慢的金色佛光。点开某一行，最底下是「在 DSH 里打开这个对话 →」，一点就跳回去。

数字不糊弄：token 是这个会话从头到现在的累计，时间是真花在模型和工具上的墙钟时间，不是「会话开了几小时」。口径全摊在下面那张表里。

## 闲事：敲两下木鱼，翻两页经

她闲下来的本事只有两样。

点她身体中间，「梆」一声，飘一句「功德 +1」——也可能是财富、桃花运、好运、健康，图个乐子，别当真。累计数两边共用，敲多少是多少。

或者翻开那张浅杏色的古书卡片，读两句经。内置六部汉传常诵经典、共 129 句，每句都配着原文、逐句释义、名相、当天能做的练习。也能从 fojing.com 再取一部回来，但**只取原文**：释义留成「原文草稿 · 释义待补」，不拿机器编的解释冒充讲解。

## 她的三种形态

- **网页浮层**：长在 DSH 窗口的右下角，跟着窗口走；窗口一关，她也就没了。
- **桌面壳**：点「放她到桌面」，她变成一个透明置顶的独立窗口，能拖到任何地方，DSH 关了她还在（Windows）。
- **三档尺寸**：100% / 80% / 62%，最大就是原尺寸；缩的时候脚底不动，不会悬在半空。

> 名字的由来：坐在**莲**台上打坐的**鲸**鱼娘，合起来就是「莲鲸」。她安静，「鲸」又有点像「惊」，我尽量不惊动你。

| **多部经可选** | 学习面板顶部是经书选择器，六部经随时切换，各自独立记进度 |

## 联网取经

入口在「今日读经」页头（`取经` 按钮，空语料时也在），点进去是经目列表 + 一个可以贴 fojing.com 经文页链接的输入框；从哪儿进来的，退出去就回哪儿（`回到读经页` / `回到逐句读`）。

取回来的**只有原文**，写进 `corpus/<id>.json` 并登记进 `corpus/index.json`，重启后就是内置经书之一。`gist` / `terms` / `practice` 会留成「原文草稿 · 释义待补」：释义是人写的东西，机器抓不来，不拿自动生成的解释冒充讲解。

撤掉：删掉那个 json + 从 `index.json` 的 `sutras` 里删一行。

## 安装

要 **DSH 桌面版**（Windows）。

先把丑话说前面：npm 上还没发：注册账号要过 www.npmjs.com 那关，国内经常打不开。所以官方「发现」里搜不到她，得走下面三条路之一。装法都不复杂，挑一条顺手的：

1. **有安装包**：下载 → 一条命令（最省事，给同事也这么发）
2. **想点着装**：DSH 里加一个索引源，之后在「发现」里点「安装」
3. **想改着玩**：链接本地源码，改完刷新页面就生效

三种方式殊途同归：都会把插件登记进 profile 的 `dsh.profile.bundles`，不用手改配置。

**方式一：安装包（给同事最省事）**

到 [Releases](https://github.com/33333cheche-web/dsh-plugin-lianjing/releases) 下载 `dsh-plugin-lianjing-2.0.2.tgz`（或 `.zip`，内容一样），然后：

```powershell
dsh plugin --profile desktop add "D:\下载\dsh-plugin-lianjing-2.0.2.tgz"
```

**方式二：在 DSH 里点着装（不用命令行，也不用 npm）**

插件 → **发现** → 右上「索引源」/「管理索引源…」→ **添加索引源**，粘贴这份索引的地址：

```
https://cdn.jsdelivr.net/gh/33333cheche-web/dsh-plugin-lianjing@main/market/index.json
```

确定后「莲鲸」会出现在列表里，点**安装**即可。索引里记的是固定到提交的 `git+https` 地址，装到的就是对应版本，不会跟着 main 乱跑。

> 用 jsDelivr 而不是 `raw.githubusercontent.com`，是因为后者在国内经常连不上。索引本身（`market/index.json`）就是[格式 1](https://github.com/33333cheche-web/dsh-plugin-lianjing/blob/main/market/index.json) 的插件市场索引，DSH 自带的校验器能直接读。

**方式三：从源码链接**（自己改着玩用这种，改完刷新页面就生效，宿主的改动重启 DSH 后生效）

```powershell
git clone https://github.com/33333cheche-web/dsh-plugin-lianjing.git
dsh plugin --profile desktop add "link:D:\path\to\dsh-plugin-lianjing"
```

撤掉用 `dsh plugin --profile desktop remove dsh-plugin-lianjing`。

**装完必须重启 DSH 桌面应用**（desktop profile 由 Electron 独占），右下角才会出现莲鲸。

在 DSH 的插件列表里，她用的是**自己的形象当图标**（`icon.png`，256×256，从 `assets/icon-256.png` 来的）。

> 从 1.x 升上来：包名换成了 `dsh-plugin-lianjing`（原来叫 `dsh-plugin-fojing-pet`），先 `remove` 旧的再装新的；攒的「已积功德」会自动从旧的状态文件搬过来，不会清零。

## 界面

下面这部分偏说明书：给想改代码、调参数的人看。只想装来用的话，看到「安装」就够了。

### 1. 界面内桌宠（右下角）

悬浮在 Harness 上，拖动可移动。点她展开卡片。

她右上角有一枚**灵感光点**（不是数字角标）：一小团会呼吸的暖金光，没有描边、没有外圈，有未读时亮、没事时暗，但一直在，点它就是展开/收起，不用再猜那里能不能点。

整体能缩：卡片底部的 `大 中 小`（100% / 80% / 62%）只缩她这一层，卡片文字不跟着缩（62% 连字一起缩就没法读了）；缩放从脚底往上收，缩完不悬空、不压人。

卡片是**浮层**，不参与排版：上方空间够就向上弹，不够就往下开，贴到左右边缘会自动往里挪，高度按剩余空间收，小屏（1366×768 那种）也不会撑破画面。桌面壳在跑的时候，网页里这只自动隐身，只留一枚「收回桌宠」。

### 1.5 眼神

三张立绘是三种眼睛，对应三种注意力朝向：

| | 眼睛 | 说的是 |
|---|---|---|
| 入定 | 全闭 | 向内 |
| 看经 | 半垂（捧着经卷） | 向下 |
| 看你 | 睁大（空手结印） | 向外 |

**睁眼只发生在跟你有关的那一拍**：点开卡片先抬眼看你 0.4 秒再低头捧经；收起时合卷抬眼 0.6 秒；读完一部抬眼 1.5 秒；被拖动时一直睁着。翻到下一句不睁眼：换一句还是读，抬头等于自己打断自己。

有未读的时候她也不常亮睁眼（那是干瞪眼），而是每 20 秒抬眼看你两三秒就走，其余时间继续入定，角标留着。

### 1.6 两个壳，别搞混

- **界面内那只**：长在 Harness 窗口里，随窗口走。关掉窗口她就没了。
- **桌面壳**（卡片里的「放她到桌面」）：独立的 Windows 窗口，浮在**所有窗口最上层**，可以拖到任何地方，Harness 关了她还在。点「收回桌宠」或右键「退出」才走。

点「放她到桌面」之后界面里那只**不会立刻消失**：壳是独立进程，冷启动要两秒多才把窗口画出来，这期间网页里这只继续站着，等壳报到才交接，按钮上显示「叫她出来中…」。她落在**鼠标所在那块屏**的右下角：多显示器下，DSH 在哪块屏，她就在哪块屏出现。

### 3. 逐句学习面板

顶部是**经书选择器**（六部经的圆角胶囊），下面依次是经名、简介、`已读 3 / 11 句`、进度条，再往下是全部句子。点某一句就地展开：释义 → 名相（词 + 解释）→ 今日练习。已读的序号变绿，点过即记入 `readSegments`，重启不丢。

### 4. 独立桌面壳（Windows）

`desktop/pet-shell.ps1` 用纯 WPF 写，不依赖第三方库：

- 透明、无边框、始终置顶，不抢焦点（`ShowActivated=false`）
- 自己算拖动位移：光标物理像素 ÷ DPI 缩放 = 窗口 DIP，175% 缩放下也不会甩出屏幕
- 单击展开/收起卡片；拖动后自动夹回工作区内
- 立绘上**不挂 ToolTip**（悬停气泡 1 秒后会弹出来把点击吃掉），底部也不放常驻提示
- 卡片里直接有**经书胶囊**（心经 / 金刚经 / 普门品 / 吉祥经），点一下就从那部经的第一句未读重新出卡
- 右键菜单：复位位置 / 收起卡片 / 退出桌宠
- 卡片顶部两个 tab：**功课（默认）/ 今日读经**；功课页每 5 秒拉一次数据，收起时每 15 秒只为更新小标签
- 功课页按项目归成树（最多 8 个会话）：同一个项目下的几个会话收在一个项目节点下，项目行显示「几个会话 / 在跑几个 / token 合计 / 最近活动」，点项目行收起整组
- 展开行底部有 `在 DSH 里打开这个对话 →`：壳是独立进程、够不到网页的 `uiWorkspace`，所以它把请求 POST 给宿主的 `/dsh-lianjing/open`，网页那侧下一拍拉快照时接力切过去（壳开着时网页端轮询从 20 秒提到 2.5 秒，点完两三秒就跳）
- 数据变少或空态时窗口会自己缩回去，不留一大片透明空白
- 底部两个小标签**常显**：`N 分钟后再读` + `已积功德 N`（没敲过就显示 0，不会整条消失）
- 右上角同样是一枚**呼吸发光的灵感光点**（替换掉原来的数字角标），点它展开/收起
- 卡片底部有 `大 中 小` 三档（100% / 80% / 62%），整只宠物连标签一起缩，档位记在状态文件里；三档下敲木鱼、拖动、展开卡片都实测过
- 20 秒轮询状态，离线时显示「离线 · 连不上 DSH」
- 卡片页脚固定、正文可滚动，滚动条换成 7px 圆角胶囊样式
- 窗口高度按内容自适应，换经书不会被裁顶
- 手动启动壳时可以加 `-Origin http://127.0.0.1:<端口>` 指定宿主地址（宿主自己拉起的那个会自动带）。`-Opaque` 是个手动开关，宿主的「放她到桌面」不会传，只在个别显卡/远程桌面下退回不透明窗口时用

数据走插件注册的**回环路由**（`/dsh-lianjing/*`），只给本机的桌面壳用，三道门：Host 必须是 `127.0.0.1` / `localhost`（挡 DNS rebinding）、所有请求都要带 `x-dsh-lianjing: 1` 自定义头（跨站页面发不出来）、写操作还要求 `application/json` 的 body。网页端不用这套，它走宿主带鉴权的 `/api/dsh-lianjing.*`。`POST /next` 可以带 `{ "sutraId": "xin-jing" }` 指定从哪部经出卡，不带就顺着语料顺序走。

### 5. 功课面板（读 DSH 自己的活儿）

卡片顶部两个 tab：`功课` / `今日读经`。**功课是默认页**，打开卡片先看活儿，想看经再点右边那页。功课页列的是**你 DSH 里的会话**，按项目归成树：同一个项目下的几个会话收成一个项目节点，点项目行可以收起整组：

```
[功课•] [今日读经]                        ×
1 个在跑   共 92 个会话               刚刚
● 个人学习   3 个 · 1 个在跑    合计 2.4 亿   20 分钟前  ▾
│  ● 佛经学习插件开发计划
│    2/5  ▬▬▱▱▱       2.41 亿 tok       20 分钟前
│  ● 希望能通过飞书微信链接 dsh
│    6/6  ▬▬▬▬▬        351.1 万 tok       1 小时前
└  ● 上传 dsh 插件到官方市场
     419.9 万 tok                        18 小时前
● cheche   2 个                  合计 119.5 万   1 天前  ▾
```

项目行是汇总（几个会话、在跑几个、token 合计、最近活动），子行才是单个会话；点项目行收起整组，点子行照旧展开详情：

点一行就地展开：

```
子任务
✓ 探明 DSH 会话数据形状
◔ Web 功课页：多会话列表 + 展开详单
○ 桌面壳功课面板（WPF）
token 1.47 亿      轮次 22
LLM 4 小时 38 分    工具 1 小时 45 分
子 agent · 1
● 你在 Windows 上调查 DSH 内部 API     1761.8 万
────────────────────────────────
在 DSH 里打开这个对话 →
```

那个按钮点了会切到对应会话（客户端 `uiWorkspace.openSession(id)`）。拿不到这个服务、这行没有 id、或者切的时候抛错，都会在按钮下面写一句人话，不会点了没反应。

**数字口径**（这里最容易糊弄人，所以说清楚）：

| 数字 | 从哪来 | 什么意思 |
|---|---|---|
| `1.47 亿 tok` | `tokenUsage` 投影，入 + 出 + 缓存读写四项相加 | **这个会话从头到现在的全会话累计**，不是本轮 |
| `LLM / 工具` | `sessionStats` 投影的 `llmMs` / `toolMs` | **真正花在模型和工具上的墙钟时间**，不是会话活了多久 |
| `4 小时 38 分` | 会话在跑时显示 `createdAt → now` | 会话**从创建到现在**的总时长 |
| `2 分钟前` | `lastPromptAt` 距今 | 最后一次有动静是多久以前 |
| 子任务 | `todos` 投影 | agent 用 `todo_write` 自己维护的计划，没写过就没有 |

**佛光**：有会话在跑时，立绘背后转一圈缓慢的金色柔光（网页端和桌面壳用同一张 `assets/halo.png`，网页端再糊 7px 让边化开，不画硬边细环）；开工和收工各睁一次眼，跑的过程中一直闭眼。她是陪着，不是盯着你。底部小标签也会变成「N 个功课进行中」，右边并排一枚「已积功德 N」（没敲过就是 0，一直在）。

两端用的是同一张 `assets/halo.png`（512×512，环带在半径 55%~83%，alpha 最高 140），网页端 `background-image` 铺上去再 `blur(7px)` 糊开、`rotate` 转 5.5 秒一圈；桌面壳是 WPF，用 `RotateTransform` + `DoubleAnimation` 转、`Running` 时淡入、闲时淡出后 `Collapsed`。宿主没给 `sprites.halo` 时，网页端退回原来那版 `conic-gradient` 细环，不会开天窗。两边比例一致：直径 = 立绘高度 × 206/196，圆心在立绘顶部往下 53% 处。

**数据怎么来的**：全部由宿主侧一次折叠好，挂在 `/dsh-lianjing/work.json`，网页和桌面壳读同一份 JSON（都不去解析几百 MB 的会话日志）：

- `ctx.sessionQuery.listSessions()` 列全部会话（含冷会话，带 `createdAt`、`cwd`、`agentPreset`）
- `ctx.sessionQuery.observeSession(id)` 读某个会话的投影（`todos` / `tokenUsage` / `sessionStats` / `title`）
- `ctx.agents.get(id)?.status === 'running'` 判断在不在跑

子 agent 挂在父会话下面，所以「一个项目 + 它的子任务 + 它派出去的子 agent」是同一棵树。宿主侧有 2.5 秒快照缓存 + 按会话的投影缓存（在跑的 3 秒、空闲的 20 秒），第一次约 1.2 秒，之后 30 毫秒。

### 6. 敲木鱼

点她**身体中间**那一下（不是头部、不是四周），「梆」一声，她轻轻一沉，头顶飘出一句彩头：

```
        功德 +1
        桃花运 +1
  
         ( 莲鲸打坐 )
```

- 五种彩头随机：**功德 / 财富 / 桃花运 / 好运 / 健康**，各 +1
- 命中区是立绘中间一块椭圆（宽 60%、高 52%、中心略偏下）；**点四周、头部、底部小标签仍然是展开卡片**，不会互相抢
- 彩头由**宿主随机**并累计，网页和桌面壳看的是同一份账（`state.merits` + `muyuCount`），重启不丢；宿主连不上就本地随机，照样能敲
- 音效是**随包素材** `assets/muyu.wav`（19 KB / 220 ms，44.1 kHz 单声道，由 `scripts/make-muyu.mjs` 合成，不是扒来的音频）。配方：618 Hz 主体（52 ms 衰减）+ 1265 Hz 眨眼的高频（19 ms）+ 315 Hz 低腔（85 ms）+ 4 ms 噪声当木槌；合成脚本里另有 `--variant deep|mid|bright` 三档更「空心木块」的做法（成对失谐的非整数泛音 + 音高下坠），试过但听下来还是 `classic` 这一版最像，所以随包用 classic
- 网页端会先预载这个 wav，每次敲 `currentTime=0` 再 `play()`；被浏览器拦下或者文件取不到，就用 WebAudio 现场合成一记「梆」，**点了有声音**（留痕在 `window.__fjSoundLog`，最多 40 条）。声音出不来绝不影响飘字和计数
- 桌面壳启动时把这 19 KB 下到临时目录用 `SoundPlayer` 预载，没下到会在后面的轮询里自动重试
- 攒了多少显示在功课页页脚（`已积功德 N`）和小标签上
- 飘出来的彩头是**咖金色的一行字**（`#C69A4E`、加粗、无底板无边框无图标），第一下正中，连敲依次往两边错开
- 敲下去那一下换成 `knock` 立绘（手里是小木槌和木鱼），420ms 后回到原来那张；没有这张图就停在当前立绘，不会开天窗
- 四张立绘同一画布 460×479、底部对齐（内容框都是 `(12,33,448,479)`），切换不跳；生成图由 `scripts/make-knock-sprite.py` 抠白底对齐

## 语料怎么来的

`text` 一律**脚本切片**，不手抄：

```
_raw/*.txt            从 fojing.com 抓的正文（_tools/fetch-sutras.mjs）
_tools/build-*.mjs    按行区间切分、断言区间连续且覆盖全文、写 corpus/*.json
corpus/index.json     经目清单（version 2）：列出六个语料文件名
```

`gist`（释义）、`terms`（名相）、`practice`（练习）是另写的学习辅助内容，不冒充某位古德的原话，也不抄现代讲记。

重建语料：

```powershell
node _tools\build-jingang.mjs
node _tools\build-pumen.mjs
```

## 读经参谋（agent preset）

`cordis.patch.yml` 里注册了 `lianjing` 预设，新建会话即可用。它的规矩写在 `skill/lianjing-vademecum/SKILL.md`，运行时由 Host 注入语料路径与篇目索引：

1. 先把问题定位到具体的经和句子，定位不到就说定位不到；
2. 引号里的原文必须逐字来自 `text` 字段，一个字都不能改；
3. `gist` 是释义、`terms` 是名相、`practice` 是练习，都是学习辅助，不能说成经文原句；
4. 回答结构：哪部经第几句 → 逐字原文 → 释义（可展开名相）→ 今天的观察练习。

- 敲木鱼飘出来的「功德 / 财富 / 桃花运 / 好运 / 健康 +1」**是玩笑**，不做任何承诺，也不进任何真实记录，就是点一下有个声响。
