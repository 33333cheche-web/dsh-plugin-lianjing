# 莲鲸 · 佛经学习桌宠

DSH 插件。一只盘坐在莲花座上的鲸鱼娘，蹲在右下角陪你看住这一屋子的 agent——**功课面板**列着 DSH 里的会话：哪个项目在跑、子任务做到哪、烧了多少 token、跑了多久，点一下那行就能跳回对应的对话。她顺带会掏出一张**浅杏古书卡片**，一段经文原文、一段逐句释义、几条名相解释、一个当天能做的练习，「逐句读」可以把四部经一部一部读完并记住进度。点「放她到桌面」她会变成独立窗口，关掉 DSH 也还站在桌角。

内置四部汉传常诵经典，逐句分科，共 **67 句**：

| 经 | 句数 | 译者 | 底本 |
|---|---|---|---|
| 般若波罗蜜多心经 | 11 句 | 唐·玄奘 | 大正藏 T08 No.251 |
| 金刚般若波罗蜜经 | 32 分 | 姚秦·鸠摩罗什 | 大正藏 T08 No.235 |
| 观世音菩萨普门品 | 12 段 | 姚秦·鸠摩罗什 | 大正藏 T09 No.262（法华经第二十五品） |
| 吉祥经 | 12 段 | 近代·法舫 | 巴利本《小部·吉祥经》 |

## 它做什么

| 能力 | 说明 |
|---|---|
| **按时读一句** | 默认每小时轮转一句，首次启动 60 秒后来第一句；按经书顺序读，读完一部接下一部 |
| **多部经可选** | 学习面板顶部是经书选择器，四部经随时切换，各自独立记进度 |
| **逐句学习面板** | 每句都有：原文字段、逐句释义、名相解释（词 + 解释）、当天的观察练习 |
| **独立桌面壳** | 一键 spawn 一个透明置顶的 WPF 窗口，可拖动、可收起，脱离 DSH 独立运行 |
| **不编造原文** | 「经文原文」逐字来自 `corpus/*.json` 的 `text` 字段，由脚本从底本切片，不手抄 |
| **能回翻** | 卡片 `‹ ›` 看历史，`收起` / `再读一句` 是纯文字按钮 |
| **不打扰** | 默认 22:00–06:00 免打扰，每天最多 12 张 |
| **离线可用** | 内容全部来自本地语料，不调用模型 |
| **位置记忆** | 界面里的位置记在 localStorage，桌面壳可拖动并记住位置 |
| **联网取经** | 「今日读经」页头常驻的「取经」按钮，或桌面壳右键菜单，从 fojing.com 再取一部原文（白名单站点） |
| **功课面板** | 卡片的默认页读 DSH 自己的会话：哪个项目在跑、子任务做到哪、烧了多少 token、花了多久；有活在跑时立绘背后亮一圈佛光 |
| **点行跳回对话** | 功课页展开一行，详情底部有「在 DSH 里打开这个对话 →」，直接切到那个会话（靠客户端 `uiWorkspace.openSession`；拿不到服务会给一句人话提示，不静默） |
| **灵感光点** | 右上角不再是数字角标，而是一枚呼吸发光的金色光点：亮 = 有未读，暗 = 没事，**永远不消失**，点它就是展开/收起面板 |
| **尺寸三档** | 大 100% / 中 80% / 小 62%，网页浮层和桌面壳都有，最大档就是原尺寸；档位本地记住 |
| **敲木鱼** | 点她身体中间「梆」一声，随机飘一句 功德 / 财富 / 桃花运 / 好运 / 健康 +1，累计数存在宿主侧两边共用 |

## 联网取经

入口在「今日读经」页头（`取经` 按钮，空语料时也在），点进去是经目列表 + 一个可以贴 fojing.com 经文页链接的输入框；从哪儿进来的，退出去就回哪儿（`回到读经页` / `回到逐句读`）。

取回来的**只有原文**，写进 `corpus/<id>.json` 并登记进 `corpus/index.json`，重启后就是内置经书之一。`gist` / `terms` / `practice` 会留成「原文草稿 · 释义待补」——释义是人写的东西，机器抓不来，不拿自动生成的解释冒充讲解。

撤掉：删掉那个 json + 从 `index.json` 的 `sutras` 里删一行。

| 文件 | 状态 | 触发 |
|---|---|---|
| `pet-idle.png` | 闭目打坐 | 默认待机 |

## 安装

```powershell
node 佛经学习\install-plugin.mjs
```

脚本做的事：在 `~/.dsh/plugins/dsh-plugin-fojing-pet` 建一个指向本目录的**目录联接**（这样 profile 的 `package.json` 里不会出现中文路径）→ 备份 profile 的 `package.json` → 加入依赖与 `dsh.profile.bundles` → `pnpm install`。

**装完必须重启 DSH 桌面应用**（desktop profile 由 Electron 独占），右下角才会出现莲鲸。

在 DSH 的插件列表里，她用的是**自己的形象当图标**（`icon.png`，256×256，从 `assets/icon-256.png` 来的），简介也按她现在的活儿重写了——先说的是「桌宠 · 帮你看住所有 agent」，佛经是附带的，不再是「一个学经的」。

还原：`package.json.bak-<时间戳>` 拷回 profile 目录，再 `pnpm install`。

## 配置

```yaml
- id: dsh-fojing-pet
  config:
    enabled: true
    everySeconds: 3600      # 每小时
    firstDelaySeconds: 60   # 启动后 60s 先来一句
    quietHours: [22, 6]     # 本地时间 22:00–06:00 不打扰
    dailyLimit: 12          # 每天最多出卡数
    maxCards: 60            # 历史保留条数
```

## 界面

### 1. 界面内桌宠（右下角）

悬浮在 Harness 上，拖动可移动。点她展开卡片。

她右上角有一枚**灵感光点**（不是数字角标）：有未读时亮、没事时暗，但一直在，点它就是展开/收起——不用再猜那里能不能点。

整体能缩：卡片底部的 `大 中 小`（100% / 80% / 62%）只缩她这一层，卡片文字不跟着缩（62% 连字一起缩就没法读了）；缩放从脚底往上收，缩完不悬空、不压人。

卡片是**浮层**，不参与排版：上方空间够就向上弹，不够就往下开，贴到左右边缘会自动往里挪，高度按剩余空间收——小屏（1366×768 那种）也不会撑破画面。桌面壳在跑的时候，网页里这只自动隐身，只留一枚「收回桌宠」。

### 1.5 眼神

三张立绘其实是三种眼睛，对应三种注意力朝向：

| | 眼睛 | 说的是 |
|---|---|---|
| 入定 | 全闭 | 向内 |
| 看经 | 半垂（捧着经卷） | 向下 |
| 看你 | 睁大（空手结印） | 向外 |

**睁眼只发生在跟你有关的那一拍**：点开卡片先抬眼看你 0.4 秒再低头捧经；收起时合卷抬眼 0.6 秒；读完一部抬眼 1.5 秒；被拖动时一直睁着。翻到下一句不睁眼——换一句还是读，抬头等于自己打断自己。

有未读的时候她也不常亮睁眼（那是干瞪眼），而是每 20 秒抬眼看你两三秒就走，其余时间继续入定，角标留着。

### 1.6 两个壳，别搞混

- **界面内那只**：长在 Harness 窗口里，随窗口走。关掉窗口她就没了。
- **桌面壳**（卡片里的「放她到桌面」）：独立的 Windows 窗口，浮在**所有窗口最上层**，可以拖到任何地方，Harness 关了她还在。点「收回桌宠」或右键「退出」才走。

点「放她到桌面」之后界面里那只**不会立刻消失**——壳是独立进程，冷启动要两秒多才把窗口画出来，这期间网页里这只继续站着，等壳报到才交接，按钮上显示「叫她出来中…」。她落在**鼠标所在那块屏**的右下角：多显示器下，DSH 在哪块屏，她就在哪块屏出现。

### 3. 逐句学习面板

顶部是**经书选择器**（四部经的圆角胶囊），下面依次是经名、简介、`已读 3 / 11 句`、进度条，再往下是全部句子。点某一句就地展开：释义 → 名相（词 + 解释）→ 今日练习。已读的序号变绿，点过即记入 `readSegments`，重启不丢。

### 4. 独立桌面壳（Windows）

`desktop/pet-shell.ps1` —— 纯 WPF，无第三方依赖：

- 透明、无边框、始终置顶，不抢焦点（`ShowActivated=false`）
- 自己算拖动位移：光标物理像素 ÷ DPI 缩放 = 窗口 DIP，175% 缩放下也不会甩出屏幕
- 单击展开/收起卡片；拖动后自动夹回工作区内
- 立绘上**不挂 ToolTip**（悬停气泡 1 秒后会弹出来把点击吃掉），底部也不放常驻提示
- 卡片里直接有**经书胶囊**（心经 / 金刚经 / 普门品 / 吉祥经），点一下就从那部经的第一句未读重新出卡
- 右键菜单：复位位置 / 收起卡片 / 退出桌宠
- 卡片顶部两个 tab：**功课（默认）/ 今日读经**；功课页每 5 秒拉一次数据，收起时每 15 秒只为更新小标签
- 功课页按项目归成树（最多 8 个会话）：同一个项目下的几个会话收在一个项目节点下，项目行显示「几个会话 / 在跑几个 / token 合计 / 最近活动」，点项目行收起整组
- 展开行底部有 `在 DSH 里打开这个对话 →`：壳是独立进程、够不到网页的 `uiWorkspace`，所以它把请求 POST 给宿主的 `/dsh-fojing-pet/open`，网页那侧下一拍拉快照时接力切过去（壳开着时网页端轮询从 20 秒提到 2.5 秒，点完两三秒就跳）
- 数据变少或空态时窗口会自己缩回去，不留一大片透明空白
- 底部两个小标签**常显**：`N 分钟后再读` + `已积功德 N`（没敲过就显示 0，不会整条消失）
- 右上角同样是一枚**呼吸发光的灵感光点**（替换掉原来的数字角标），点它展开/收起
- 卡片底部有 `大 中 小` 三档（100% / 80% / 62%），整只宠物连标签一起缩，档位记在状态文件里；三档下敲木鱼、拖动、展开卡片都实测过
- 20 秒轮询状态，离线时显示「离线 · 连不上 DSH」
- 卡片页脚固定、正文可滚动，滚动条换成 7px 圆角胶囊样式
- 窗口高度按内容自适应，换经书不会被裁顶
- `-Opaque` 开关可在个别显卡/远程桌面下退回不透明窗口

数据走插件注册的**免鉴权回环路由**（`/dsh-fojing-pet/*`）：只读 GET，写操作要求 `x-dsh-fojing-pet` 自定义请求头 **且带 `application/json` 的 body**，跨站请求拿不到这个头，所以不会被网页 CSRF。`POST /next` 可以带 `{ "sutraId": "xin-jing" }` 指定从哪部经出卡，不带就顺着语料顺序走。

### 5. 功课面板（读 DSH 自己的活儿）

卡片顶部两个 tab：`功课` / `今日读经`——**功课是默认页**，打开卡片先看活儿，想看经再点右边那页。功课页列的是**你 DSH 里的会话**，按项目归成树：同一个项目下的几个会话收成一个项目节点，点项目行可以收起整组：

```
[功课•] [今日读经]                        ×
1 个在跑   共 92 个会话               刚刚
● 个人学习   3 个 · 1 个在跑    合计 2.4 亿   20 分钟前  ▾
│  ● 佛经学习插件开发计划
│    2/5  ▬▬▱▱▱       2.41 亿 tok       20 分钟前
│  ● 希望能通过飞书微信链接 dsh
│    6/6  ▬▬▬▬▬        351.1 万 tok       1 小时前
└  ● 上传 dsh 插件到官方市场
     419.9 万 tok                        18 小时前
● cheche   2 个                  合计 119.5 万   1 天前  ▾
```

项目行是汇总（几个会话、在跑几个、token 合计、最近活动），子行才是单个会话；点项目行收起整组，点子行照旧展开详情：

点一行就地展开：

```
子任务
✓ 探明 DSH 会话数据形状
◔ Web 功课页：多会话列表 + 展开详单
○ 桌面壳功课面板（WPF）
token 1.47 亿      轮次 22
LLM 4 小时 38 分    工具 1 小时 45 分
子 agent · 1
● 你在 Windows 上调查 DSH 内部 API     1761.8 万
────────────────────────────────
在 DSH 里打开这个对话 →
```

那个按钮点了会切到对应会话（客户端 `uiWorkspace.openSession(id)`）。拿不到这个服务、这行没有 id、或者切的时候抛错，都会在按钮下面写一句人话，不会点了没反应。

**数字口径**（这里最容易糊弄人，所以说清楚）：

| 数字 | 从哪来 | 什么意思 |
|---|---|---|
| `1.47 亿 tok` | `tokenUsage` 投影，入 + 出 + 缓存读写四项相加 | **这个会话从头到现在的全会话累计**，不是本轮 |
| `LLM / 工具` | `sessionStats` 投影的 `llmMs` / `toolMs` | **真正花在模型和工具上的墙钟时间**，不是会话活了多久 |
| `4 小时 38 分` | 会话在跑时显示 `createdAt → now` | 会话**从创建到现在**的总时长 |
| `2 分钟前` | `lastPromptAt` 距今 | 最后一次有动静是多久以前 |
| 子任务 | `todos` 投影 | agent 用 `todo_write` 自己维护的计划，没写过就没有 |

**佛光**：有会话在跑时，立绘背后转一圈缓慢的金色光；开工和收工各睁一次眼，跑的过程中一直闭眼——她是陪着，不是盯着你。角标和底部小标签也会变成「N 个在跑」。

网页端是 CSS 的 `conic-gradient` + 径向遮罩（`.fj-halo`，9 秒一圈、有活时 5.5 秒）；桌面壳是 WPF，同样的效果烘成一张 `assets/halo.png`（512×512，环带在半径 55%~83%），用 `RotateTransform` + `DoubleAnimation` 转、`Running` 时淡入、闲时淡出后 `Collapsed`。两边比例一致：直径 = 立绘高度 × 206/196，圆心在立绘顶部往下 53% 处。

**数据怎么来的**：全部由宿主侧一次折叠好，挂在 `/dsh-fojing-pet/work.json`，网页和桌面壳读同一份 JSON（都不去解析几百 MB 的会话日志）：

- `ctx.sessionQuery.listSessions()` 列全部会话（含冷会话，带 `createdAt`、`cwd`、`agentPreset`）
- `ctx.sessionQuery.observeSession(id)` 读某个会话的投影（`todos` / `tokenUsage` / `sessionStats` / `title`）
- `ctx.agents.get(id)?.status === 'running'` 判断在不在跑

子 agent 挂在父会话下面，所以「一个项目 + 它的子任务 + 它派出去的子 agent」是同一棵树。宿主侧有 2.5 秒快照缓存 + 按会话的投影缓存（在跑的 3 秒、空闲的 20 秒），第一次约 1.2 秒，之后 30 毫秒。

### 6. 敲木鱼

点她**身体中间**那一下（不是头部、不是四周）——「梆」一声，她轻轻一沉，头顶飘出一句彩头：

```
        功德 +1
        桃花运 +1
  
         ( 莲鲸打坐 )
```

- 五种彩头随机：**功德 / 财富 / 桃花运 / 好运 / 健康**，各 +1
- 命中区是立绘中间一块椭圆（宽 60%、高 52%、中心略偏下）；**点四周、头部、底部小标签仍然是展开卡片**，不会互相抢
- 彩头由**宿主随机**并累计，网页和桌面壳看的是同一份账（`state.merits` + `muyuCount`），重启不丢；宿主连不上就本地随机，照样能敲
- 音效是**随包素材** `assets/muyu.wav`（19 KB，44.1 kHz 单声道，由 `scripts/` 里的合成脚本生成，不是扒来的音频）
- 网页端会先预载这个 wav，每次敲 `currentTime=0` 再 `play()`；被浏览器拦下或者文件取不到，就用 WebAudio 现场合成一记「梆」兜底，**保证点了有声音**（留痕在 `window.__fjSoundLog`，最多 40 条）。声音出不来绝不影响飘字和计数
- 桌面壳启动时把这 19 KB 下到临时目录用 `SoundPlayer` 预载，没下到会在后面的轮询里自动重试
- 攒了多少显示在功课页页脚（`已积功德 N`）和小标签上
- 飘出来的彩头是**咖金色的一行字**（`#C69A4E`、加粗、无底板无边框无图标），第一下正中，连敲依次往两边错开
- 敲下去那一下换成 `knock` 立绘（手里是小木槌和木鱼），420ms 后回到原来那张；没有这张图就停在当前立绘，不会开天窗
- 四张立绘同一画布 460×479、底部对齐（内容框都是 `(12,33,448,479)`），切换不跳；生成图由 `scripts/make-knock-sprite.py` 抠白底对齐

## 语料怎么来的

`text` 一律**脚本切片**，不手抄：

```
_raw/*.txt            从 fojing.com 抓的正文（_tools/fetch-sutras.mjs）
_tools/build-*.mjs    按行区间切分、断言区间连续且覆盖全文、写 corpus/*.json
corpus/index.json     经目清单（version 2）：列出四个语料文件名
```

`gist`（释义）、`terms`（名相）、`practice`（练习）是另写的学习辅助内容，不冒充某位古德的原话，也不抄现代讲记。

重建语料：

```powershell
node 佛经学习\_tools\build-jingang.mjs
node 佛经学习\_tools\build-pumen.mjs
```

## 佛经学习参谋（agent preset）

`cordis.patch.yml` 里注册了 `fojing-pet` 预设，新建会话即可用。它的规矩写在 `skill/fojing-vademecum/SKILL.md`，运行时由 Host 注入语料路径与篇目索引：

1. 先把问题定位到具体的经和句子，定位不到就说定位不到；
2. 引号里的原文必须逐字来自 `text` 字段，一个字都不能改；
3. `gist` 是释义、`terms` 是名相、`practice` 是练习，都是学习辅助，不能说成经文原句；
4. 回答结构：哪部经第几句 → 逐字原文 → 释义（可展开名相）→ 今天的观察练习。

## 边界

- 不判定修行境界，不承诺消灾、治病、开悟、转运；
- 不做宗派高下之判，遇到教义争议说明「这是不同理解」；
- 经文原文与释义、名相分开呈现，不混在一起；
- 不替代医疗、法律、投资建议；用户处于明显痛苦中时建议寻求现实中的专业帮助；
- 敲木鱼飘出来的「功德 / 财富 / 桃花运 / 好运 / 健康 +1」**是玩笑**，不做任何承诺，也不进任何真实记录——就是点一下有个声响。
